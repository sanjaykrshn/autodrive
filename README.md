# Sheepdog

**Sheepdog: Autonomous Livestock Herding Agent**

Sheepdog is a project about creating an autonomous in-game helper that guides livestock toward player-designated enclosures. The project explores practical, nonviolent herding behavior and reliable multi-animal guidance while keeping the player in control of each task.
